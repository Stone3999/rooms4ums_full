   -> DETALLES (La publicación en classroom para la tarea que debíamos entregar): 
   "Práctica 13: Entregar a más tardar Jueves 23, a las 23:00 hrs.
   Comprender la administración de cuentas de usuario en un sistema operativo, aplicando las operaciones de creación, modificación, habilitación, deshabilitación y verificación de estados de usuarios, así como el análisis de las implicaciones de seguridad y administración.

   Las cuentas de usuario permiten controlar el acceso a los recursos del sistema operativo.
   Una cuenta puede encontrarse en dos estados principales:
   Habilitada: el usuario puede autenticarse normalmente.
   Deshabilitada: la cuenta permanece almacenada en el sistema, pero el usuario no puede iniciar sesión.
   Deshabilitar una cuenta es una buena práctica cuando:
   Un empleado deja temporalmente la organización.
   Se detecta actividad sospechosa.
   Un estudiante concluye un curso pero podría regresar.
   Se requiere conservar la información del usuario sin eliminarla.
   Eliminar una cuenta implica perder su configuración y puede ocasionar problemas de auditoría.

   Crear tres usuarios, dos del mismo nivel y uno invitado (ej. alumno1, alumno2, invitado) con la misma contraseña para cada uno. Anexar evidencia de la creación.

   Para cada usuario identificar:
   Nombre completo
   Estado de la cuenta
   Fecha de creación
   Último inicio de sesión
   Pertenece a qué grupos
   Si requiere cambio de contraseña
   Completar una tabla con las siguientes columnas: usuario, habilitado, grupo, cambio de contraseña. Anexar evidencia.

   Deshabilitar uno de los dos usuario con jerarquía igual:
   Verificar:
   ¿Aparece como deshabilitado?
   ¿Puede iniciar sesión?
   Registrar evidencia mediante captura de pantalla.

   Volver a habilitar el usuario.
   Comprobar:
   ¿Puede iniciar sesión?
   ¿Qué propiedad cambió?
   Registrar evidencia.

   Realizar pruebas de ejecución de comandos para deshabilitar usuarios. Anexar evidencia.

   Completar la tabla. Filas: Deshabilitar usuario, eliminar usuario, Columnas: Acción, ¿Se conserva la información?, ¿Puede iniciar sesión?, ¿Puede recuperarse fácilmente?
